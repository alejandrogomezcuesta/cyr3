# Apuntes de teoría - Computación y Robótica 3º ESO

## Secuencia anual

1. Introducción a la programación: Python, algoritmos, variables, condiciones, bucles y entrada/salida.
2. Desarrollo móvil: interfaces, eventos y sensores con Thunkable.
3. Desarrollo web: HTML, servidores, animación y prácticas básicas con Visual Studio Code y Anvil.
4. Computación física: sistemas, microcontroladores, hardware, software y seguridad.
5. Internet de las cosas: sensores, nube y protocolos.
6. Robótica: grados de libertad, articulaciones, configuraciones, AGV y micro:bit.
7. Datos masivos: metadatos y scraping responsable.
8. Inteligencia Artificial: agentes, aprendizaje automático, refuerzo y ética.
9. Ciberseguridad: malware, protección, plataformas y propiedad intelectual.

## Recursos y metodología

Se priorizan herramientas gratuitas o disponibles en el centro. Las prácticas con sensores se realizan con el simulador de MakeCode y, cuando el material lo permita, con micro:bits y sensores básicos reales. Las actividades se documentan con capturas, código, tablas, diagramas o breves explicaciones.

## Evaluación y seguimiento

La evaluación combina observación, productos digitales, prácticas, pruebas de tema, autoevaluación y coevaluación. Las sesiones de cierre permiten recuperar aprendizajes y construir un portfolio final.
